⚙️ ตั้งค่าระบบ

📍 ปุ่มลัด LandsMaps (พิกัด + ภาพแปลง)
ใช้บนคอม (Chrome / Edge) · ทำครั้งเดียว: ลากปุ่มเขียวด้านล่างไปวางที่แถบบุ๊กมาร์ก
📍 ส่งแปลงเข้า Auction Tracker
  1. ในการ์ดทรัพย์ กด 🔎 เปิด LandsMaps แล้วล็อกอิน (ThaiID) ให้หน้าต่างข้อมูลแปลงขึ้น
  2. กดบุ๊กมาร์ก 📍 ส่งแปลงเข้า Auction Tracker → กด 📸 ถ่ายภาพ + ส่ง → เลือก "แท็บนี้" แล้วกดแชร์
  3. กลับมาที่แอป ตรวจทรัพย์ที่เลือกให้ แล้วกด บันทึก
🔔 แจ้งเตือนวันนัดประมูล
เด้งบนมือถือแม้ไม่ได้เปิดแอป · เลือกเปิด/ปิดได้ 2 แบบ (มีผลทุกเครื่อง)
🔴 ทุกนัดทุกทรัพย์

☁️ Cloud & เครื่องนี้
เครื่องนี้จำ PIN ไว้แล้ว เปิดแอปครั้งต่อไปเข้าได้ทันที · เครื่องใหม่ใส่ PIN ครั้งเดียวก็จำเช่นกัน
—
เปลี่ยน PIN = เครื่องใหม่ต้องใช้ PIN ใหม่ (เครื่องที่จำไว้แล้วยังเข้าได้ตามเดิม) · ลืม PIN มีผลเฉพาะเครื่องนี้ ข้อมูลบน Cloud ไม่หาย
🗺️ Google Maps (แท็บสำรวจ)
key ต้องเปิด Maps JavaScript API + Geocoding API และจำกัดโดเมนเป็นเว็บนี้ · บันทึกช่องว่าง = ลบ key กลับไปใช้ OpenStreetMap
💾 สำรอง / กู้คืนข้อมูล
ดาวน์โหลดไฟล์ JSON เก็บไว้เป็นเซฟตี้ ถ้า Cloud พัง — Import กลับได้
🗄️ พื้นที่จัดเก็บ
ลบรูปภาพ = ลบเฉพาะรูป ข้อมูลยังอยู่ · ลบทรัพย์ = ลบข้อมูลทรัพย์และค่าใช้จ่ายที่เกี่ยวข้องทั้งหมด
