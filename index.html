✈️ Telegram
🖥 Browser
วิธีตั้งค่า Telegram Bot:
1. แชทกับ @BotFather → พิมพ์ /newbot → ตั้งชื่อ → รับ Token
2. แชทกับ Bot ของคุณก่อน 1 ครั้ง (เพื่อให้ระบบรู้จัก Chat ID)
3. เปิด https://api.telegram.org/bot[TOKEN]/getUpdates แล้วดู chat.id
แจ้งเตือนผ่าน การแจ้งเตือนของ Browser — ไม่ต้องสมัครอะไร
กด "ขอสิทธิ์แจ้งเตือน" แล้ว Allow ที่ Browser จะแจ้งเตือนผ่าน OS อัตโนมัติ

💬 การแจ้งเตือน — LINE Messaging API (ฟรี 200 ข้อความ/เดือน)
วิธีตั้งค่า (ทำครั้งเดียว ~15 นาที):
1. เปิด developers.line.biz → Log in ด้วย LINE
2. กด Create a new provider → ตั้งชื่อ → Create
3. กด Create a new channel → เลือก Messaging API
4. กรอกข้อมูล channel → Create → ยืนยัน email
5. แท็บ Messaging API → เลื่อนลงหา Channel access token → กด Issue → Copy
6. แท็บ Basic settings → เลื่อนลงหา Your user ID → Copy (ขึ้นต้น U...)
7. เปิด LINE → Add เพื่อน OA ที่สร้างขึ้น (scan QR ในหน้า Messaging API)
☁️ Cloud Sync — Supabase (ฟรี)
สมัครที่ supabase.com → สร้าง Project → Settings → API → copy URL + anon key
จากนั้นรัน SQL ใน SQL Editor ของ Supabase: 
create table auction_data (
  user_key text primary key,
  data jsonb not null,
  updated_at timestamptz default now()
);
alter table auction_data enable row level security;
create policy "open" on auction_data for all using (true) with check (true);
เครื่องอื่นใส่รหัสเดิมแล้วกด ⬇️ Sync เพื่อดึงข้อมูล
